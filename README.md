## 🇺🇸 English

### Overview
Business Intelligence and data analysis project built with a **synthetic dataset** designed to simulate and control a business model. The pipeline covers data cleaning and standardization in **Python**, relational storage and connection via **PostgreSQL**, and interactive visualization in **Power BI**.

The dataset, labels, and dashboard visuals are structured in **English** to make exploration and analysis accessible to a global audience.

> **Note on Data:** The data used in this project is synthetic, created for business model simulation, operational control, and portfolio demonstration purposes.

### Pipeline / Workflow
1. **Data Cleaning (Python):** Removal of unnecessary null and duplicate records, and standardization of inconsistent names/fields.
2. **Database & Connection (PostgreSQL):** Storage and structured querying of cleaned data in a relational database connected to Power BI.
3. **Visualization & Control (Power BI):** Tracking of core KPIs, sales trends, country performance, and top-selling products.

### Dashboard Preview
![Dashboard Overview](imagens/dashboard-visao-geral.png)

### Key Metrics & Analyses (KPIs)
- **Total Revenue:** Overall revenue generated across the analyzed period.
- **Total Products Sold:** Total volume of units sold.
- **Total Orders:** Total number of orders recorded to monitor transaction flow.
- **Total Customers:** Customer base served by the business model.
- **Sales Trend:** Time-series evolution to identify growth, seasonality, or drops.
- **Sales by Country:** Geographic distribution and comparison across markets.
- **Top-Selling Products:** Ranking of highest-volume products to support inventory, assortment, and commercial decisions.

### Tools & Technologies
- **Python:** Data cleaning (handling nulls and duplicates) and name standardization.
- **PostgreSQL:** Relational database storage and BI integration.
- **Power BI:** Data modeling, KPIs, and interactive visual reporting.
- **Synthetic Dataset:** Created to simulate and monitor a business model.

### How to Explore
1. Download the `.pbix` file from this repository.
2. Open it in **Power BI Desktop**.
3. Use the interactive filters and visuals to explore metrics, trends, countries, and products.

## 🇧🇷 Português

### Visão Geral
Projeto de Business Intelligence e análise de dados desenvolvido a partir de uma **base de dados fictícia** criada para simular e controlar um modelo de negócio. O fluxo contempla limpeza e padronização dos dados com **Python**, armazenamento e conexão via **PostgreSQL** e visualização interativa no **Power BI**.

A base, os rótulos e os visuais do dashboard foram estruturados em **inglês** para facilitar a análise por um público internacional.

> **Nota sobre os dados:** Os dados utilizados neste projeto são fictícios, criados para fins de modelagem de negócio, simulação de controle operacional e portfólio.

### Fluxo do Projeto
1. **Limpeza de Dados (Python):** Remoção de registros nulos e duplicados desnecessários e padronização de nomes/campos não padronizados.
2. **Banco de Dados e Conexão (PostgreSQL):** Armazenamento e consulta estruturada dos dados tratados em banco relacional conectado ao Power BI.
3. **Visualização e Controle (Power BI):** Acompanhamento de KPIs, tendência de vendas, desempenho por país e produtos mais vendidos.

### Preview do Dashboard
![Visão Geral do Dashboard](imagens/dashboard-visao-geral.png)

### Principais Métricas e Análises (KPIs)
- **Receitas Totais (*Total Revenue*):** Visão geral do faturamento gerado no período analisado.
- **Produtos Totais Vendidos (*Total Products Sold*):** Volume total de itens comercializados.
- **Pedidos Totais (*Total Orders*):** Quantidade de pedidos registrados para acompanhar o fluxo de compras.
- **Clientes Totais (*Total Customers*):** Base de clientes atendidos no modelo de negócio.
- **Tendência de Vendas (*Sales Trend*):** Evolução temporal para identificar sazonalidade, crescimento ou quedas.
- **Vendas por País (*Sales by Country*):** Distribuição geográfica da operação e comparação entre mercados.
- **Produtos Mais Vendidos (*Top-Selling Products*):** Ranking dos itens de maior saída para apoiar decisões de estoque, sortimento e foco comercial.

### Ferramentas Utilizadas
- **Python:** Limpeza de dados (remoção de nulos e duplicados) e padronização de nomes.
- **PostgreSQL:** Armazenamento em banco relacional e integração com o relatório.
- **Power BI:** Modelagem, métricas/KPIs e visualização interativa.
- **Base fictícia:** Criada para simulação e controle de modelo de negócio.

### Como Explorar
1. Faça o download do arquivo `.pbix` presente neste repositório.
2. Abra o arquivo no **Power BI Desktop**.
3. Utilize os filtros e visuais interativos para explorar as métricas, tendências, países e produtos.
